## Overview
This program plays through a standard 8x8 Chess game using only notational input via console.
Players take turns writing notation to make their moves. For example:

1. Input: `e4` (White moves e2 pawn to e4)
2. Input: `d5` (Black moves d7 pawn to d5)
3. Input: `exd5` (White captures the pawn on d5 using their e4 pawn)

The game goes on until one player resigns, gets checkmated, or a draw is accepted.
